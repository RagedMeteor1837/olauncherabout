title: Development Builds & Project Status
---

Development builds are now published at regular intervals based on the "dev" branch on GitHub. In these builds, you can also switch your launcher's update branch directly from this tab in the launcher. This change will be coming to stable builds in the next release.<br><br>

While development releases will usually be published after a certain number of changes (as multiple small commits can happen in quick succession), every push to the "dev" branch is automatically built by GitHub Actions. You can download these builds at any time from the Actions tab on GitHub.<br><br>

Finally, over the next few months there might not be many changes as I'll be quite tied up with real-life commitments, but don’t panic! The project is still very much alive and I'll hopefully get back into it by the second half of 2026.
